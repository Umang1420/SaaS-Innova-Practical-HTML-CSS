# To Do

A simple to-do list app where you can add tasks, mark them complete, edit them, and delete them.

## How to run

1. Open the project folder.
2. Open the `index.html` file in your browser.
3. The app will load and you can start using it.

## How to use

- Click the OFF/ON button to show or hide the task input section.
- Enter a task name and description.
- Click the Add button to save the task.
- Use the checkbox to mark a task as complete.
- Use the edit and delete buttons to manage tasks.

## Features

- Add tasks with a description
- Mark tasks as complete
- Edit existing tasks
- Delete tasks
- Save tasks in the browser using local storage
