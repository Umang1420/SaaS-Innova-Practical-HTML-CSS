# External API Table

A simple web page that fetches user data from an external API and displays it in a table.

## How to run

1. Open the project folder.
2. Open the `index.html` file in your browser.
3. The page will load the user data automatically from the API.

## How to use

- Open the page in your browser.
- Wait for the data to load from the API.
- View the information displayed in the table.
- Type a name in the search input box and click the Search button to filter the list.

## Features

- Fetches user data from JSONPlaceholder
- Displays each user's name, email, address, and ID
- Filters the table results by name using the search button
