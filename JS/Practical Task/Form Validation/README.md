# Form Validation

A registration form with live validation for name, email, password, confirm password, and terms agreement.

## How to run

1. Open the project folder.
2. Open the `index.html` file in your browser.
3. The form will appear and you can start using it.

## How to use

- Enter a valid name with at least 3 characters.
- Enter a valid email address.
- Create a strong password that includes lowercase letters, uppercase letters, numbers, and a special character.
- Re-enter the same password in the confirm password field.
- Check the terms checkbox.
- The Submit button becomes enabled only when all validations pass.

## Features

- Validates user input in real time
- Shows password strength hints
- Displays error messages for invalid fields
- Enables the submit button only when the form is valid
