# Multi API

A dashboard that collects data from multiple APIs and displays it in one place.

## How it works
- Loads users, posts, and quotes from public APIs.
- Shows a summary of the total items loaded.
- Lets you toggle between user and post views.
- Quotes rotate automatically in the UI.

## How to run
- Open index.html in a browser or use Live Server.
- Internet access is required for API requests.
