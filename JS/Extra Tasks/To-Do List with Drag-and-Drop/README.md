# To-Do List with Drag-and-Drop

A simple to-do list that stores tasks in the browser and allows drag-and-drop reordering.

## How it works
- Enter a task and click Add Task.
- The task appears in the list.
- Drag tasks to reorder them.
- Tasks are saved in local storage, so they remain after refresh.

## How to run
- Open index.html in your browser or use Live Server.
