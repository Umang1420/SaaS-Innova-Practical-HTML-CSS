# Recipe Management System

A simple web app to manage recipes in the browser.

## How to use
- Add recipes with name, ingredients, time, and category
- View all saved recipes in a table
- Search recipes by ingredient
- Edit or delete recipes
- Data is saved using browser local storage

## How to Run
1. Open the folder in your browser.
2. Open the index.html file directly, or use a live server.
3. Start adding and managing recipes.
