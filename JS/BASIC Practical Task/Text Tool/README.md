# Text Analysis Tool

A simple web app that analyzes text by showing:
- Character count
- Word count
- Word frequency

## How to run
1. Open the project folder.
2. Open the file `index.html` in your browser.
3. Type text in the input box and click **Get Analysis**.

## What to do in the app
- Enter any text in the input box.
- Click **Get Analysis** to see the results.
- Click **Clear** to reset the text and results.

## Note
No installation is needed. This project runs directly in a browser.
